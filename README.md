Some community completion guides identify missable Side Tales. That makes it useful to distinguish an unfinished quest from a quest that can safely wait. A practical journal should track quest name, area, last step and the next action. It should not pretend to control the in-game quest state.

## Getting started: a practical workflow

1. Download the Windows archive using the direct GitHub Releases link.
2. Create a quest entry when you begin a Side Tale or hear a lead from an NPC.
3. Record the last confirmed step and the region; do not rely on memory after several chapters.
4. Before advancing the story, review unresolved quest entries and consult a recent walkthrough for missable details.
5. Mark resolved entries only after confirming the quest outcome in the game.

**A quest title alone is not a walkthrough.** Some quests have mutually exclusive outcomes or conditions tied to region progress. Use current quest sources and keep a manual save before important choices.
